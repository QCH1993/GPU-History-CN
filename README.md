## 原书结构（初步）

本书是 GPU 历史三卷系列的第一卷，重点介绍从 20 世纪 60 年代到 1990 年代末、通向集成 GPU 的发展历程。作者将内容分为 PC 平台和其他平台两大部分，并按时间、平台和公司综合组织。

目前已确认的主要部分包括：

- Foreword（前言）
- Preface（序言）
- Graphics Controllers on Other Platforms, 1980–1990
- Graphics Controllers on PCs, 1980–1989
- Graphics Controllers on PCs, 1990–1995
- Graphics Controllers on Other Platforms, 1990–1999
- Graphics Controller on PCs, 1996–1999
- What Is a GPU
- Glossary（术语表）
- Acronyms（缩略语）

## 翻译原则

1. 译文按章节或完整小节组织；每个文件注明对应原书页码。
2. 技术术语首次出现时尽量保留英文，随后使用统一中文译法。
3. 人名、公司名、芯片名、产品名和标准名称不擅自改写；必要时附英文原名。
4. 保留标题、脚注、图注、表格、引用、数字、年份和型号。
5. 不擅自纠正原文的历史说法；有疑问之处记录在译者注中。
6. Markdown 是编辑和审校的主格式；PDF/EPUB 仅作为可选输出物。
