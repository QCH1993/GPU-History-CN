# 前言

> 原文：[Foreword](../source/en/chapters/00-foreword.md)

> PDF 页码：5–7

历史无论是在学校里学习、作为纪录片和书籍的主题，还是通过口耳相传、代代传承，往往都会引发强烈的反应。无论来源如何，任何一段历史都不可能涵盖某个人经历过的每一件事。我的记忆每天都在证明这一点。

我认为历史是一门必不可少的学科。了解过去发生了什么，可以帮助我们认识哪些事情奏效了——也许更重要的是，哪些没有奏效，以及原因是什么。此外，历史还为当前事件提供背景。我们可以从历史中以重要的方式学习。

计算本身是一个相对年轻的领域。许多科学和工程领域的历史要悠久得多，也已经得到广泛记录。对于什么才算是第一台数字计算机，人们仍存在实质性的争论。简单地说，数字计算机的历史还不到一百多年。

计算机图形学则是一个更加年轻的领域。它融合了各种不同的显示技术、数字计算机和模拟计算机，以及人类在平面屏幕上观看图像的先天能力。波音公司威奇托分部的 Verne Hudson 大约在 1960 年创造了“computer graphics”这一术语；他的合作者 Bill Fetter 则使这一术语广为人知。

Jon 的这本书，与近期一批致力于记录计算机图形学不同侧面的著作相互补充。Peddie、Masson 和 Carlson 的著作介绍了这一领域的总体情况；Smith 追溯了像素的演变；Llach 研究了图形学在建筑和建筑设计中的应用；Weisberg 记录了 CAD 的历史；Gaboury 则探讨了犹他大学所产生的影响。这些只是其中一部分。

我认为这些作者有一点非常有趣：他们中的许多人并非严格意义上的历史学家，而是与这个领域有着密切的实际联系。其中一些人是先驱，另一些人则是先驱的学生，对自己记录的历史拥有第一手知识。这些作者的写作既有权威性，也有现场感。

本书对图形处理器（graphics processing unit）提供了广阔的视角。Jon 从第一天起就参与专用图形处理技术。他出色地记录了那些致力于更快生成更好图像的处理器。和任何历史一样，本书不可能面面俱到；但它确实为这项有价值的技术的发展提供了连贯且组织良好的视角。Jon 特别强调，GPU 是如何从专门用于生成图像的定制处理器，演变为通用并行处理器的。

这种视角有助于读者更好地理解 GPU 在计算机图形学世界中的位置。

直到 20 世纪 60 年代末，我都完全不知道 Hudson 和 Fetter，也不知道计算机与计算机图形学的存在。我直到 1962 年才进入高中。我的课程包括拉丁语、希腊语，而科学课程很少。因此，我当时甚至几乎不会拼写“computer”这个词。具有讽刺意味的是，35 年后，我从波音公司可视化与交互技术领域的高级技术 Fellow 职位上退休了。

1969 年，我还是约翰斯·霍普金斯大学的本科生时，计算机图形学就吸引了我。Bill Huggins 曾利用休假时间向贝尔实验室的先驱们学习计算机动画，后来他招募我制作计算机动画教育影片。这个过程十分艰苦，其中包括穿孔卡片、行式打印机关键帧、一台位于纽约布鲁克林的缩微胶片记录仪、一种使用汇编语言编写的动画“语言”，以及一台 IBM 7094 大型机。当时没有供动画师或程序员使用的交互式设备，没有彩色输出，没有阴影图像，也没有声音，只有黑色背景上的白线。但我喜欢这一切！

职业生涯早期，我在 Battelle-Columbus 实验室制作了更多动画影片，并学习交互式图形学。我逐渐意识到，无论一帧画面属于投影影片，还是显示在图形屏幕上，数字计算机都可以一次显示一帧。只要每幅图像显示得足够快，人类视觉系统就会完成其余工作，让人产生连续运动的错觉。

对于影片而言，放映机以足够快的速度显示画面——每秒 24–30 帧（Hz）——从而使运动看起来是连续的。交互式设备的屏幕也必须以相同或更快的速度重绘。如今，交互式设备通常采用 60 Hz 以上的重绘速率。实时绘制新画面的要求，最终推动了 GPU 相关工作的开展。一部完整长度的动画电影，可能需要数百个“计算世纪”才能生成足够的画面；而放映机负责以足够快的速度把这些画面显示出来。

GPU 通过提高总体吞吐量，帮助把一部电影所需的数百个“计算世纪”缩短到更加合理的时间。交互性则对计算性能提出了更高要求。在今天的交互式图形学世界中，GPU 必须足够快地计算出全新的画面，才能制造连续运动的错觉。换句话说，图像生成这一计算任务——也就是 GPU 所执行的任务——必须及时确定每一帧中每个像素的颜色，快到足以让人类视觉系统相信图像的变换（无论是二维还是三维）是连续的。

我在波音公司的工作强调可接受的交互性能。我曾经在一台配备 GPU 的 PC 上，以波音的规模交互式处理一架商用飞机（例如 787）的完整数字设计——大约包含 20 亿个多边形——让最终用户觉得这项任务很简单。我经常用这样一个标准来衡量成功：在实际使用时，让复杂的幕后任务看起来简单。

我认为，Jon 对 GPU 演变为通用并行处理器的讨论具有真正的价值。这印证了我的一个信念：最成功、最强大的技术，往往是那些能够被推广，并应用于最初开发者从未预见的问题的技术。GPU 正是这样一种技术。

请认真关注 GPU 演变和通用化过程中获得的经验。这些经验也可以应用到读者自己的工作中。同时，也请理解未来几代 GPU 如何能够继续扩展，从而提供更大的价值。

Sammamish，华盛顿州，美国  
D. J. Kasik  
2022 年 6 月
